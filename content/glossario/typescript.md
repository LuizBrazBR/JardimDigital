---
title: TypeScript
---

Linguagem criada pela Microsoft que é **JavaScript com tipos** por cima. Todo código JavaScript válido também é TypeScript válido — a diferença é que você pode declarar o "formato" dos dados (`string`, `number`, formato de um objeto, etc.) e o compilador avisa em tempo de desenvolvimento se algo não bate, antes mesmo de rodar o código.

Navegadores não entendem TypeScript diretamente: antes de chegar no navegador, os tipos são removidos ([[glossario/transpilacao|transpilação]]) e sobra só JavaScript puro.
