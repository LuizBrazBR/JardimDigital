> [!abstract] Definição
> **A parte da [[glossario/url|URL]] com o nome do computador onde roda o [[glossario/servidor|servidor]]: com quem conversar.** Em `https://www.loja.com.br/produtos`, o host é `www.loja.com.br`.

Os computadores se acham por números, os endereços IP. O host é o nome que as pessoas usam, e o DNS troca esse nome pelo número antes da conversa. É quase o mesmo que [[glossario/dominio|domínio]], e muita gente usa uma palavra pela outra. Quando há diferença, o domínio é o nome registrado (`loja.com.br`), e o host é o nome completo da URL (`www.loja.com.br`). O host também vai dentro da [[glossario/requisicao|requisição]], no cabeçalho `Host`. Ver a aula [[programacao/protocolos-da-web/modulo-1/02-o-que-acontece-quando-voce-digita-uma-url-e-aperta-enter|1.2 O que acontece quando você digita uma URL e aperta Enter]].

## De onde vem a palavra

Do latim *hospes*, que queria dizer ao mesmo tempo quem recebe, o anfitrião, e quem é recebido, o hóspede. Vem de uma palavra antiga que juntava "estrangeiro" e "senhor": o senhor que recebe os estrangeiros. Do mesmo *hospes* vêm **hóspede**, **hospedar**, **hospital** e **hotel**. Em português, o serviço de guardar um site num servidor se chama **hospedagem**: o host é o computador que hospeda o site.
