> [!abstract] Definição
> **O texto com as instruções de um programa, escrito numa linguagem de programação.** Também se diz *código-fonte*.

No dia a dia, "escrever código" e "[[glossario/programar|programar]]" querem dizer a mesma coisa.

## De onde vem a palavra

Do latim *cōdex*, forma popular de *caudex*: **tronco de árvore**. O caminho até o computador foi longo:

| Etapa | Sentido |
|---|---|
| *caudex*, *cōdex* | tronco de árvore |
| *cōdex* | tabuinhas de madeira cobertas de cera, onde se escrevia; depois, qualquer livro |
| *cōdex* | livro de leis organizadas |
| *código* | conjunto de regras: Código Civil, código de trânsito |
| *código* | sistema de sinais combinados: código Morse, código secreto |
| *código* | as instruções de um programa |

**Códice**, o nome dos livros manuscritos antigos, é a mesma palavra latina, emprestada de novo séculos depois.

> [!tip] Madeira dos dois lados
> *Log*, como em `console.log`, também é madeira: em inglês, é uma tora. Veja [[glossario/log|log]].
