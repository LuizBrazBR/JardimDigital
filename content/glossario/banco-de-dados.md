> [!abstract] Definição
> **Um programa especializado em guardar dados de forma permanente e achá-los rápido.** Um array some quando o programa termina. Num banco de dados, os dados ficam guardados.

O [[glossario/servidor|servidor]] conversa com o banco de dados pedindo e recebendo dados, e nessa conversa ele é o [[glossario/cliente|cliente]]. A maioria dos bancos de dados entende uma linguagem chamada SQL. Também se diz **base de dados**. Ver a aula [[programacao/protocolos-da-web/modulo-1/01-cliente-e-servidor-o-modelo-por-tras-da-web|1.1 Cliente e servidor: o modelo por trás da web]].

## De onde vêm as palavras

**Banco de dados** é, ao pé da letra, o inglês *databank*: um lugar onde os dados ficam depositados, como o dinheiro num banco. O português *banco* veio do italiano *banco*, de uma palavra germânica que queria dizer "banco, balcão". E o banco de dinheiro tem esse nome por causa da mesa dos cambistas italianos, a *banca*.

**Dado** vem do latim *datum*, de *dare*, "dar": o que foi dado. Mais em [[glossario/tipo-de-dado|tipo de dado]].
