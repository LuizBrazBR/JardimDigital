---
title: React
---

Biblioteca JavaScript para construir interfaces através de **componentes**: funções que recebem dados (`props`) e retornam a estrutura visual (JSX) que deve aparecer na tela.

O React cuida de atualizar o DOM automaticamente quando os dados mudam — você descreve "como a tela deve ficar dado esse estado", não os passos manuais de manipular elementos HTML.

Mantido pela Meta. Concorrentes diretos: Vue, Svelte, Angular.
