> [!abstract] Definição
> **Cada volta de um [[glossario/laco|laço]].** "O laço deu cinco voltas" e "o laço fez cinco iterações" dizem a mesma coisa.

O verbo é **iterar**: repetir um passo, ou passar por uma lista item por item. "Iterar sobre os produtos do carrinho" é olhar um produto, depois o próximo, até o último.

```js
for (let i = 1; i <= 3; i++) {
  console.log("volta", i);
}
// volta 1   ← 1ª iteração
// volta 2   ← 2ª iteração
// volta 3   ← 3ª iteração
```

> [!warning] Iteração não é interação
> As duas palavras só diferem pelo *n*. **Iteração** é repetição. **Interação** é *inter* + *ação*, a ação entre dois lados, como a conversa entre a pessoa e o programa.

Ver a aula [[programacao/logica-de-programacao/modulo-4/01-por-que-repetir-a-ideia-de-laco|Por que repetir: a ideia de laço]].

## De onde vem a palavra

Do latim *iterāre*, "fazer pela segunda vez, repetir", de *iterum*, "de novo, outra vez". Lá no fundo, *iterum* vem de uma raiz indo-europeia que queria dizer "outro". Iterar é fazer **outra** vez.
