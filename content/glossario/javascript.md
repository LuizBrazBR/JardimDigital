> [!abstract] Definição
> **A linguagem de programação dos navegadores.** Quase todo site interativo usa JavaScript. Com o Node.js, ela roda também fora do navegador, direto no computador.

Brendan Eich fez a primeira versão em 1995, na Netscape, em dez dias. Apesar do nome, não tem parentesco com a linguagem Java. O [[glossario/typescript|TypeScript]] é JavaScript com tipos por cima.

## De onde vem o nome

A linguagem trocou de nome duas vezes em 1995:

| Quando | Nome |
|---|---|
| no começo | Mocha |
| setembro | LiveScript |
| dezembro | JavaScript |

A Java era a linguagem da moda, e o próprio Eich considerou o nome final uma jogada de marketing da Netscape.

- **Java**: o nome vem do café de Java, da Indonésia. *Mocha*, o primeiro nome, também é nome de café.
- **Script**: do latim *scrīptum*, "escrito". Em inglês, *script* é o roteiro de uma peça ou de um filme. O código JavaScript é o roteiro que o navegador segue.
